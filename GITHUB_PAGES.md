# GitHub Pages Activation

The repository contains a **manual** GitHub Pages workflow. It does not publish the site automatically.

To publish the client-facing static site, the repository owner should:

1. Open **Settings → Pages** in the GitHub repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions** and save the change.
3. Open the repository’s **Actions** tab, select **Build GitHub Pages site**, and choose **Run workflow**.
4. When the run completes, GitHub shows the live Pages URL in the workflow summary and under **Settings → Pages**.

For this repository, the expected URL pattern is:

`https://shiyam-galyon.github.io/center-aap-ia-prototype/`

The source repository can remain private; GitHub Pages availability for private repositories depends on the owner’s GitHub plan and organization policy.
